# My Performance

Resources for Cisco US PS PMs to build smarter, goal-aligned weekly check-ins using Claude Code.

---

## What's in this repo

### `weekly-checkin-pm-setup.md`

A setup guide that walks you through building a personalized `/weekly-checkin` skill in Claude Code. Once set up, the skill pulls from your Outlook email, calendar, Webex spaces, and project documents to draft your weekly check-in in about 5 minutes — organized by your goals and aligned to the Cisco US PS FY26 strategic priorities:

- Drive Durable Growth
- Simplify for Customer Outcomes
- Leverage AI to Enhance Work

---

## How to get started

1. Open Claude Code
2. Open `weekly-checkin-pm-setup.md` from this repo
3. Copy the setup prompt and paste it into Claude Code as your first message
4. Claude will guide you through the rest — no technical knowledge needed

Setup takes about 10 minutes. Running it each week takes about 5.
